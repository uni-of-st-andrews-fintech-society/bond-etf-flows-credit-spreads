# bond-etf-flows-credit-spreads
Do bond ETF outflows (HYG/LQD) drive changes in credit spreads?

A University of St Andrews FinTech Society whitepaper project, following the
society's eight-phase whitepaper framework.

## Repo layout

| Path | Contents |
|---|---|
| `README.md` | How to reproduce every result |
| `PREREG.md` | The pre-registration (Phase 1) |
| `logs/` | Decisions, deviations, experiments, AI use, meetings |
| `data/` | Download and cleaning scripts only |
| `src/` | Analysis code |
| `results/` | Tables and figures, generated by code |
| `paper/` | The whitepaper's LaTeX source |

## Getting the data

Raw data is never committed: `data/raw/` and `.env` are git-ignored.
Instructions for obtaining the data, with and without Bloomberg access, will go
here in Phase 3.
